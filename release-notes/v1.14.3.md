# Agender v1.14.3

## Resumen

Esta versión incorpora el nuevo reporte de la red hidrometeorológica, facilita la
reemisión segura de licencias y mejora la estabilidad del almacenamiento y del
proceso de publicación.

## Novedades

- Registro y generación de mapas de lluvia y temperatura con fecha y horas
  independientes del diseño general.
- Exportación de los diseños del reporte hidrometeorológico.
- Importación de una licencia firmada anterior para completar el generador y
  emitir una revisión superior.
- Sesiones persistentes hasta cierre explícito, cambio de contraseña o pérdida
  de validez de la licencia.

## Correcciones

- El proceso de GitHub Actions vuelve a disponer del manifiesto de dependencias
  de desarrollo que necesita para validar el código.
- SQLite aplica las relaciones declaradas y espera de forma controlada cuando
  otra escritura mantiene ocupada la base.
- El servidor integrado rechaza direcciones que no sean de loopback.

## Rendimiento

- Los módulos cartográficos continúan cargándose bajo demanda.
- Se retiró una copia redundante de seis imágenes, evitando duplicar 5,66 MB en
  el árbol de trabajo.
- No se aplicaron microoptimizaciones sin una mejora demostrable.

## Seguridad

- La API integrada solo puede escuchar en la interfaz local.
- Se reforzó la integridad referencial de la base SQLite.
- Las licencias importadas se verifican criptográficamente y solo permiten
  avanzar su revisión.

## Mantenimiento interno

- Se desacopló una prueba del espacio interno del módulo de temperatura.
- Se añadieron pruebas para la interfaz de escucha y las opciones críticas de
  SQLite.
- Se eliminaron recursos gráficos duplicados sin consumidores.

## Compatibilidad

No hay cambios en el formato firmado de licencias ni migraciones destructivas.
Las licencias existentes continúan siendo válidas.

## Validaciones realizadas

- Ruff sobre backend y pruebas.
- Suite Python completa y validación de sintaxis JavaScript.
- Comprobaciones de dependencias Python, Rust/Tauri y del proceso de release.
- Construcción y verificación del instalador firmando los artefactos cuando la
  clave local de actualización está disponible.
