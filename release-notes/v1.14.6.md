# Agender v1.14.6

## Resumen

Esta versión completa la migración de las exportaciones PDF y JPG a un Chromium
headless integrado y controlado por Agender.

## Correcciones y mejoras

- Las exportaciones dejan de depender de Microsoft Edge instalado.
- Playwright utiliza una versión fija de Chromium incluida en el instalador.
- La exportación hidrometeorológica reutiliza una sola instancia para las seis
  hojas seleccionadas.
- El motor integrado funciona tanto en la aplicación instalada como mediante
  `cargo tauri dev`.
- El empaquetado ejecuta una prueba real de PDF y PNG antes de aceptar el
  backend.
- Los scripts localizan automáticamente `RC.EXE` en el Windows SDK instalado.

## Compatibilidad

No hay cambios destructivos en datos, configuración ni licencias. Esta versión
puede instalarse directamente sobre Agender 1.14.5.

## Validaciones

- Suite Python completa y Ruff.
- Validación de sintaxis JavaScript.
- Prueba real de PDF y PNG desde el backend PyInstaller.
- Construcción y verificación del instalador NSIS y su firma.
