# Agender v1.16.8

## Clima y climatología mensual

- Se incorpora el módulo **Clima** con el submódulo **Climatología mensual**.
- Permite configurar estaciones representativas de temperatura y precipitación
  para la zona urbana y las cuencas del Yanuncay, Tomebamba, Tarqui y
  Machángara.
- Genera seguimientos mensuales de temperatura y precipitación con gráficos
  diarios, mensuales, históricos, bandas P10–P90 y análisis adaptados a los
  datos disponibles.
- Los reportes pueden exportarse a PDF por territorios seleccionados, con dos
  páginas por territorio y el mismo diseño mostrado en la aplicación.

## Datos y análisis

- El procesamiento climatológico se ejecuta íntegramente en Python y utiliza
  los archivos del Registro hidrometeorológico configurado.
- Las temperaturas mensuales representan los extremos absolutos registrados
  durante cada mes.
- Las bandas históricas excluyen el año analizado y se ajustan al día o mes
  correspondiente.
- Se corrigió la lectura de precipitaciones decimales para conservar valores
  como `0.1`, `0.2` y `1.2 mm` en los acumulados diarios y mensuales.

## Licencias, impresión y mantenimiento

- El generador de licencias permite habilitar Clima y su submódulo
  Climatología mensual de forma independiente.
- La exportación PDF utiliza el motor integrado y admite Chrome o Edge como
  respaldo cuando el navegador empaquetado no está disponible.
- Se retiraron componentes, estilos y rutas de diseños climatológicos
  anteriores, junto con la implementación heredada en R.
- No hay cambios destructivos en datos, perfiles ni configuraciones. Agender
  1.16.8 puede instalarse directamente sobre versiones anteriores.
