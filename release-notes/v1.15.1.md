# Agender v1.15.1

## Novedades

- Los mapas de lluvia y temperatura conservan sus plantillas y mapas base al
  ejecutarse en equipos con configuraciones diferentes.
- La fecha y hora del registro de temperatura seleccionan correctamente la
  observación horaria de IERSE. `Hora inicial` y `Hora final` se utilizan
  únicamente para el rango presentado en el mapa.
- Los campos de registro muestran formatos estables: `AAAA-MM-DD` para lluvia y
  `AAAA-MM-DD HH:mm` para temperatura.
- Los seis diseños hidrometeorológicos se exportan a JPG componiendo la plantilla
  local con las capas dinámicas, evitando imágenes incompletas o fondos vacíos.
- La exportación PDF de Calidad del agua y las exportaciones JPG utilizan el
  Chromium integrado, sin depender de Microsoft Edge instalado.

## Rendimiento y estabilidad

- Las plantillas JPG ya no se convierten ni transfieren en Base64 durante cada
  exportación, reduciendo memoria y tiempo de preparación.
- Los trabajos de lluvia y temperatura comparten un registro sincronizado con
  copias defensivas.
- Se conserva la carga diferida de DuckDB, Polars, Viewer y tareas
  hidrometeorológicas para mantener rápido el inicio de Agender.
- El instalador verifica el motor Chromium, la generación PDF/PNG, el trabajador
  de inventario, la API local, los recursos y la firma antes de publicarse.

## Compatibilidad

No hay cambios destructivos en datos, perfiles, configuración ni licencias.
Agender 1.15.1 puede instalarse directamente sobre versiones anteriores.

## Validación

- 170 pruebas automatizadas.
- Ruff, validación de JavaScript y Clippy sin advertencias.
- Instalador NSIS y artefactos de actualización firmados.
