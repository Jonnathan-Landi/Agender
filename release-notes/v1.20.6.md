# Agender v1.20.6

## Hotfix de Climatología mensual

- Se corrige el error `No module named 'backend.climatology_renderer'` que
  podía aparecer al generar seguimientos térmicos y de precipitaciones desde
  la aplicación instalada.
- El renderizador de Climatología se incorpora mediante una importación
  explícita para garantizar su inclusión dentro del backend empaquetado.
- Se conservan todas las mejoras visuales y de estabilidad publicadas en
  Agender 1.20.5.

## Garantías de empaquetado

- La validación de release inspecciona el archivo interno de PyInstaller y
  exige la presencia de `backend.climatology_renderer`.
- El ejecutable empaquetado ejecuta una nueva prueba de humo que importa el
  renderizador y comprueba los estilos de temperatura y precipitación.
- Una compilación incompleta ahora falla antes de crear o publicar la release.

## Compatibilidad

- No hay cambios destructivos en documentos, perfiles ni configuraciones.
  Agender 1.20.6 puede instalarse directamente sobre 1.20.5 y versiones
  anteriores.
